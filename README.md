### Hướng dẫn chạy trên máy cá nhân (Local)
Nếu giám khảo muốn chạy trực tiếp từ mã nguồn đã tải về:
1. Không mở trực tiếp file `index.html` bằng cách double-click (trình duyệt sẽ chặn quyền truy cập pixel của Canvas qua giao thức `file://`).
2. Vui lòng sử dụng **Live Server** (trên VS Code) hoặc chạy một local server (ví dụ: `python -m http.server`) tại thư mục gốc của dự án.
